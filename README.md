# Steam 家庭组 · 游戏贡献度计算器

[![test](https://github.com/fgnbfgzdnb/steam-family-contribution-for-fun/actions/workflows/test.yml/badge.svg)](https://github.com/fgnbfgzdnb/steam-family-contribution-for-fun/actions/workflows/test.yml)

把一个 Steam 家庭组（最多 6 人共享游戏）里每个人的**贡献度**按当前国区折扣价折算出来，
回答一个问题：**这个家庭组里，谁在真正地往外掏游戏？**

计分看的是**「你的游戏有没有被别人玩过」**，不是「你买了多少」——
囤了一堆没人碰过的游戏，在这个口径下不加分。

一条命令跑完，得到一份可以双击打开、也可以直接发给别人的单文件 HTML 报告。

> ⚠️ `access_token` 是**账号级凭据**（等同于你的 Steam 登录态）。本项目**不需要你把它交给任何人**：
> 在你自己的电脑上跑，token 只被拿去请求 Steam，**不写进任何文件、不经过任何第三方服务**，进程结束就没了。
> 取到之后请**直接回来跑，中途别再刷新任何 Steam 网页**（页面每次加载都会换发新 token、旧的立刻作废，
> 这是报 401 的头号原因）。

## 快速开始

需要 **Node 18+** 和一个 Steam `access_token`（取法见下一节，约 1 分钟）。
**不需要 `npm install`** —— 本项目零运行时依赖。

```bash
node steam-family.js
```

Windows 也可以双击 `run.bat`，macOS / Linux 跑 `./run.sh`（两个脚本只做一件事：
确认你装了 Node，然后把上面这条命令跑起来）。跑完会自动打开报告，**进程随即退出**。

报告是一份**自包含的单文件 HTML**（样式、脚本、数据全在里面），可以直接发给别人，对方双击就能看。

### 参数

| 参数 | 作用 |
|---|---|
| `--out <path>` | 报告输出到哪（默认 `./steam-family-report.html`）。★ 只能是**当前目录内**的 `.html`/`.htm` |
| `--original` | 报告默认按**标价**展示（不写则用当前国区折扣价） |
| `--no-open` | 生成后不自动打开浏览器 |
| `--from <json>` | 离线：吃一份已保存的数据文件，完全不联网。★ 只能是**当前目录内**的 `.json` |
| `--token <t>` | 直接给 token，不交互（★ 会留在 shell 历史与进程列表里，优先用环境变量） |

> **为什么路径被限死在当前目录**：这个工具是要发给别人跑的，其中有人会从聊天记录里
> 复制一条命令。把「只读写当前目录里的文件」做成一条件硬规则，比事后解释省事得多 ——
> 报告本来也是生成出来给人看的，放在哪儿都行。想放到别的目录就先 `cd` 过去再跑。

### 环境变量

| 变量 | 说明 |
|---|---|
| `STEAM_ACCESS_TOKEN` | 配了就不用交互式粘贴 token |
| `HTTPS_PROXY` | 需要显式指定代理时才设（工具不会自己猜端口） |
| `STEAM_FORCE_DIRECT=1` | 完全禁用代理，只走直连 |
| `STEAM_FAMILY_CACHE` | 改缓存目录（默认是系统用户级缓存目录） |

## access_token 怎么拿（Chrome，约 1 分钟）

先打开**家庭组管理页** <https://store.steampowered.com/account/familymanagement/>
（能看到组员，说明登录态正常），然后按 `F12`：

- **方法一（最快）**
  1. 切到 **Network** 面板 → 筛选栏点 **Fetch/XHR**
  2. 保持面板开着，按 `Ctrl+Shift+R` 硬刷新
  3. `Ctrl+F` 搜 `access_token`
  4. 双击那条请求 → 在 **Request URL** 里选中 `access_token=` 后面那串值，复制
     （只要那串字符本身，别把开头的 `&` 或结尾的 `?` 一起选上）

- **方法二（搜不到请求时用，一定拿得到）**
  1. `Ctrl+Shift+R` 硬刷新 → 切到 **Console**
  2. 第一次粘贴会被 Chrome 拦下，手动输入 `allow pasting` 回车（只需一次）
  3. 粘贴这行回车，token 直接进剪贴板：
     ```js
     copy(JSON.parse(application_config.dataset.loyalty_webapi_token))
     ```

★ 两种方法拿到的是同一枚 token。**取完立刻回来粘进终端，中途别再刷新或打开任何 Steam 网页。**

## 计分规则

**一款游戏值多少，不看「谁买了它」，看「它有没有被别人玩过」。**

设某款游戏当前国区折扣价为 `P`，家庭组共 `N` 人，其中 `O` 人拥有，另有 `M` 位**非拥有者实际玩过**它：

```
该游戏产生的共享价值 = M × P          // 有多少人真的玩到了，就产生多少份价值
每位拥有者记分        = (M × P) ÷ O    // 价值由 O 位拥有者均摊
```

举例（`N = 6`，`P = 328`）：

| 拥有者 O | 实际玩过 M | 每位拥有者得分 |
|---|---|---|
| 1 人 | 5 人 | `5 × 328 ÷ 1 = 1640` |
| 2 人 | 4 人 | `4 × 328 ÷ 2 = 656` |
| 3 人 | 3 人 | `3 × 328 ÷ 3 = 328` |
| 1 人 | 0 人（买了没人玩） | `0` |

**这些情况记 0 分**：

| 状态 | 原因 |
|---|---|
| 无人拥有 | 根本不在家庭组库里 |
| 免费游戏 | `P = 0` |
| **不支持家庭共享** | 别人根本玩不到 |
| 全员拥有 | 没人因此受益 |
| **无人玩过** | 有人拥有也能共享，但没有任何非拥有者玩过它 |

其它约定：

- **谁玩过**由 Steam 的游玩记录决定，**有一条记录就算数**（不设时长门槛）。
- 拥有者自己玩自己的游戏**不算** —— 那没给别人带来任何价值。
- **价格默认取当前国区折扣价**，反映「现在要花多少钱才能玩到」；报告里可以切到**标价**对比。
  ★ 价格**每次执行都现查、不落缓存**，所以报告里的数字只代表运行那一刻。
- 港区 / 新加坡 / 美区补的价会按实时汇率折算成人民币。
- **两个维度**：`贡献`（你的游戏被别人玩出多少价值）与 `使用`（你白玩了别人多少）；
  **净贡献 = 贡献 − 使用**，贡献榜按它从高到低排。
- **不变量**：所有人的贡献分之和 ≡ 所有人「白玩到的价值」之和。

## 报告里有什么

| 区域 | 内容 |
|---|---|
| 计分规则 | 这套分怎么算的（含「什么情况记 0 分」） |
| 家庭组成员 | 头像 + 昵称 |
| 贡献榜 | 每个人的贡献 / 使用 / 净贡献，双向柱状图；顶部可切换折扣价与标价 |
| 逐游戏明细 | 拥有者、使用者及其游玩时间、单份贡献、项目总贡献；可按提供者与使用者筛选 |

明细默认只列**真正产生了共享价值**的游戏，并按价值排序；也可以取消筛选看全部，
或按拥有人数、价格、名称排序。默认只渲染前若干行，下方「展开更多」每次追加 50 行。

## 隐私与凭据

- **`access_token` 不落盘**：只从命令行参数 / 环境变量 / 交互式输入获得，进程结束就没了。
- **落盘的只有一个缓存**：成员昵称与头像，24 小时过期，写在**系统用户级缓存目录**
  （Windows `%LOCALAPPDATA%`、macOS `~/Library/Caches`、Linux `$XDG_CACHE_HOME`），
  **不在项目目录里**，可以用 `STEAM_FAMILY_CACHE` 改。里面没有任何凭据。
  价格不缓存，每次现查。
- **报告里是组里真人的信息**（昵称、头像、SteamID、整份游戏库与游玩时长）——
  **别把报告转发到家庭组以外**。要给别人看结果，发数字截图比发整份报告稳妥。
- **报告头像是外链**（`avatars.steamstatic.com`）：收件人打开时浏览器会去 Steam CDN 取头像，
  也就是**他的 IP 与打开时间对 Steam 可见**；断网打开则只显示文字头像。
  想连这一点也不出网，把数据里的 `avatar` 字段清空再生成即可。
- **不需要任何 Web API Key**：全项目只用 `access_token` 一种凭据，昵称头像走 Steam 社区那条
  **免密钥**接口。仓库里**不含任何内置凭据**，也不会去用别人的。
- **出网目标就这几个**：`api.steampowered.com`、`store.steampowered.com`、`steamcommunity.com`、
  `avatars.steamstatic.com`，加上一个第三方汇率接口 `open.er-api.com`（免费免密钥，
  请求里只有货币代码，不带 token、不带任何个人信息；它挂了就退回内置兜底汇率）。
  没有遥测，没有隐藏回传地址。
- **交互式粘贴 token 时不回显**：屏幕上不会出现那串字符（只有你粘贴的动作）——
  录屏或旁人看不到它。

## 排错

```bash
npm run check
```

它会逐项告诉你哪一层断了：代理、取价接口、家庭共享判定、家庭组读取、昵称解析。

- **读家庭组报 401 → 十有八九是 token 被「轮换作废」，不是过期。**
  Steam 页面每加载一次就换发一枚新 token，旧的那枚立刻失效（哪怕还没到期）。
  → 硬刷新家庭组管理页重新取一次，**取完直接回来跑**，中途别再点任何 Steam 页面。
  其次才考虑过期（寿命约 24 小时）。
- **价格查得到、家庭组却读不了 → 代理没覆盖 `api.steampowered.com`。**
  读家庭组只能走 api 域，没有降级路径；换个覆盖 api 域的加速器节点，或设 `HTTPS_PROXY`。
- **提示「这个账号没有加入任何 Steam 家庭组」→ token 是好的**，换组里其他人的 token 即可。
- **成员显示成「玩家XXXXXX」→ 昵称接口偶发限流**，重跑一次通常就好；
  价格、归属、计分都不受影响。
- **直接双击 `index.html` 打不开数据 → 这是正常的**：它只是报告模板，本身不含数据。
  跑 `node steam-family.js`（或双击 `run.bat`）才会生成带数据的报告。

## 目录结构

```
steam-family.js        入口：一条命令出报告
run.bat / run.sh       双击入口（Windows / macOS·Linux）
cli.js                 只输出终端报表，不生成 HTML
src/engine.js          计分内核（纯函数、零依赖、无 DOM）
src/steam.js           Steam 接口接入
src/payload.js         字段组装
src/safe-path.js       路径闸门（--from / --out 只碰当前目录）
src/static-report.js   把模板内联成单文件报告
src/app.js             报告的渲染逻辑
index.html styles.css  报告模板
data/sample.json       示例数据
tests/                 测试（含发布闸门）
.github/               CI 与 issue / PR 模板
```


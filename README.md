# Steam 家庭组 · 游戏贡献度计算器

[![test](https://github.com/fgnbfgzdnb/steam-family-contribution-for-fun/actions/workflows/test.yml/badge.svg)](https://github.com/fgnbfgzdnb/steam-family-contribution-for-fun/actions/workflows/test.yml)

把一个 Steam 家庭组（最多 6 人共享游戏）里每个人的**贡献度**按当前国区折扣价折算出来，
用于回答：**谁在向家庭组净输出游戏价值。**

计分依据是实际游玩记录，而非购买记录 —— **你的游戏是否被别人玩过**。
拥有但无人游玩的游戏在该口径下不产生分数。

执行一条命令即可得到一份单文件 HTML 报告，可直接打开，也可转发给他人。

> ⚠️ `access_token` 是**账号级凭据**（等同于 Steam 登录态）。本项目**不需要你把它交给任何人**：
> 仅在本机执行，token 只用于请求 Steam，**不写进任何文件、不经过任何第三方服务**，随进程结束消失。
> 取得后请**立即执行，中途别再刷新任何 Steam 网页**（页面每次加载都会换发新 token、旧的立即作废，
> 这是返回 401 的首要原因）。

## 快速开始

需要 **Node 18+** 和一个 Steam `access_token`（取法见下一节，约 1 分钟）。
**不需要 `npm install`** —— 本项目零运行时依赖。

```bash
node steam-family.js
```

Windows 可直接双击 `run.bat`，macOS / Linux 执行 `./run.sh`（两者仅做一件事：确认已安装 Node，
再执行上述命令）。完成后自动打开报告，**进程随即退出**。

报告是一份**自包含的单文件 HTML**（样式、脚本与数据全部内联），可直接转发，对方打开即可查看。

### 参数

| 参数 | 作用 |
|---|---|
| `--out <path>` | 报告输出路径（默认 `./steam-family-report.html`）。★ 只能是**当前目录内**的 `.html`/`.htm` |
| `--original` | 报告按**标价**展示（省略时使用当前国区折扣价） |
| `--no-open` | 生成后不自动打开浏览器 |
| `--from <json>` | 离线：读取已保存的数据文件，全程不联网。★ 只能是**当前目录内**的 `.json` |
| `--token <t>` | 以参数直接提供 token，不进入交互（★ 会留在 shell 历史与进程列表中，优先使用环境变量） |

> **为什么路径限定在当前目录**：本工具面向他人分发，使用者可能直接从聊天记录中复制命令执行。
> 将「只读写当前目录内的文件」设为硬性规则，优于事后逐条解释 ——
> 报告本身即供查看，置于何处均可。如需输出到其他目录，请先切换工作目录再执行。

### 环境变量

| 变量 | 说明 |
|---|---|
| `STEAM_ACCESS_TOKEN` | 已设置时无需交互式粘贴 token |
| `HTTPS_PROXY` | 仅在需要显式指定代理时设置（工具不会自行探测端口） |
| `STEAM_FORCE_DIRECT=1` | 完全禁用代理，仅走直连 |
| `STEAM_FAMILY_CACHE` | 修改缓存目录（默认为系统用户级缓存目录） |

## 如何获取 access_token（Chrome，约 1 分钟）

先打开**家庭组管理页** <https://store.steampowered.com/account/familymanagement/>
（能看到组员，说明登录态正常），然后按 `F12`：

- **方法一（最快）**
  1. 切到 **Network** 面板 → 筛选栏点 **Fetch/XHR**
  2. 保持面板开着，按 `Ctrl+Shift+R` 硬刷新
  3. `Ctrl+F` 搜 `access_token`
  4. 双击那条请求 → 在 **Request URL** 里选中 `access_token=` 后面那串值，复制
     （仅需该字符串本身，不要连带开头的 `&` 或结尾的 `?`）

- **方法二（前一种方式取不到时使用，必定可获得）**
  1. `Ctrl+Shift+R` 硬刷新 → 切到 **Console**
  2. 第一次粘贴会被 Chrome 拦下，手动输入 `allow pasting` 回车（只需一次）
  3. 粘贴这行回车，token 直接进剪贴板：
     ```js
     copy(JSON.parse(application_config.dataset.loyalty_webapi_token))
     ```

★ 两种方法取得的是同一枚 token。**取得后请立即粘贴到终端执行，中途别再刷新或打开任何 Steam 网页。**

## 计分规则

**一款游戏的分值取决于它是否被别人实际玩过，而非谁购买了它。**

设某款游戏当前国区折扣价为 `P`，家庭组共 `N` 人，其中 `O` 人拥有，另有 `M` 位**非拥有者实际玩过**它：

```
该游戏产生的共享价值 = M × P          // 有多少非拥有者实际玩到，就产生多少份价值
每位拥有者记分        = (M × P) ÷ O    // 价值由 O 位拥有者均摊
```

举例（`N = 6`，`P = 328`）：

| 拥有者 O | 实际玩过 M | 每位拥有者得分 |
|---|---|---|
| 1 人 | 5 人 | `5 × 328 ÷ 1 = 1640` |
| 2 人 | 4 人 | `4 × 328 ÷ 2 = 656` |
| 3 人 | 3 人 | `3 × 328 ÷ 3 = 328` |
| 1 人 | 0 人（无人游玩） | `0` |

**这些情况记 0 分**：

| 状态 | 原因 |
|---|---|
| 无人拥有 | 不在家庭组共享库内 |
| 免费游戏 | `P = 0` |
| **不支持家庭共享** | 其他成员无法通过共享取得 |
| 全员拥有 | 无人因此受益 |
| **无人玩过** | 可共享且有人拥有，但没有任何非拥有者游玩过 |

其它约定：

- **谁玩过**以 Steam 的游玩记录为准，**存在记录即计入**（不设时长门槛）。
- 拥有者游玩自己的游戏**不计入** —— 该行为不产生对外共享价值。
- **价格默认取当前国区折扣价**，反映当前取得成本；报告中可切换为**标价**对比。
  ★ 价格**每次执行都现查、不落缓存**，因此报告中的数字仅代表运行时刻。
- 港区 / 新加坡 / 美区补充的价格按实时汇率折算为人民币。
- **两个维度**：`贡献` —— 你的游戏为他人产生的等值价值；`使用` —— 你从他人共享中获得的等值
  收益（命令行输出记作「白玩到」）。**净贡献 = 贡献 − 使用**，贡献榜按该值降序排列。
- **不变量**：所有人的贡献分之和 ≡ 所有人的「使用」之和。

## 报告内容

| 区域 | 内容 |
|---|---|
| 计分规则 | 计分方式说明（含记 0 分的各类情形） |
| 家庭组成员 | 头像 + 昵称 |
| 贡献榜 | 每个人的贡献 / 使用 / 净贡献，双向柱状图；顶部可切换折扣价与标价 |
| 逐游戏明细 | 拥有者、使用者及其游玩时间、单份贡献、项目总贡献；可按提供者与使用者筛选 |

明细默认仅列出**已产生共享价值**的游戏并按价值排序；可取消筛选查看全部，
或按拥有人数、价格、名称排序。默认只渲染前若干行，「展开更多」每次追加 50 行。

## 隐私与凭据

- **`access_token` 不落盘**：仅来自命令行参数、环境变量或交互式输入，随进程结束消失。
- **落盘的只有一个缓存**：成员昵称、头像与主页链接等公开信息，24 小时过期，写在**系统用户级
  缓存目录**（Windows `%LOCALAPPDATA%`、macOS `~/Library/Caches`、Linux `$XDG_CACHE_HOME`），
  **不在项目目录里**，可通过 `STEAM_FAMILY_CACHE` 修改。其中不含任何凭据。
  价格不缓存，每次现查。
- **报告包含组内成员的真实身份信息**（昵称、头像、SteamID、整份游戏库与游玩时长）——
  **别把报告转发到家庭组以外**。对外展示结果时，提供数字截图比转发整份报告更稳妥。
- **报告头像是外链**（`avatars.steamstatic.com`）：收件人打开时浏览器会向 Steam CDN 请求头像，
  即**其 IP 与打开时间对 Steam 可见**；无网络时回退为文字头像。
  如需连这一点也不出网，将数据中的 `avatar` 字段清空后重新生成。
- **不需要任何 Web API Key**：全项目仅使用 `access_token` 一种凭据，昵称与头像通过 Steam 社区
  的**免密钥**接口获取。仓库里**不含任何内置凭据**，也不使用任何他人的凭据。
- **出网目标仅限于此**：`api.steampowered.com`、`store.steampowered.com`、`steamcommunity.com`、
  `avatars.steamstatic.com`，另加一个第三方汇率接口 `open.er-api.com`（免费、免密钥，
  请求仅包含货币代码，不携带 token 与任何个人信息；不可用时回退至内置兜底汇率）。
  无遥测，无隐藏回传地址。
- **交互式粘贴 token 时不回显**：屏幕不会显示该字符串（仅可见粘贴动作），录屏与旁观者均无法取得。

## 能力与数据边界

本工具是一个本地脚本：以使用者提供的 `access_token` 请求其浏览器会话本就在访问的 Steam Web
接口，将返回 JSON 中的价格与游玩记录计算为贡献分。

- **不修改 Steam 客户端与内容。** 全部行为限于 HTTPS 请求与 JSON 解析：不含二进制分析、
  不解析协议封包、不模拟客户端、不绕过任何授权检查。
- **不采集、不上传。** 没有服务端、没有遥测、没有回传地址；计算全部在本机完成，产物是一份
  本地 HTML 文件。出网目标限于上一节列出的域名。
- **权限不超过该 token 自身。** 不携带任何内置凭据，也不获取额外的访问能力：以某一账号的凭据调用，
  只能读到该账号自己所属的家庭组；该账号未加入任何家庭组时，接口明确返回未加入状态。
- **只读取计分所需字段。** 报告中每个成员仅保留 steamid、accountId、昵称、头像与主页链接；
  昵称接口一并返回的 `real_name`、`city`、`country` 等字段一律丢弃（由单元测试约束）；
  在线状态仅存在于中间处理层，不进入报告。
  不抓取成员主页、不遍历好友关系、不读取家庭组以外的游戏库。
- **凭据不落盘。** token 仅来自命令行参数、环境变量或交互式输入，随进程结束消失。

⚠️ 报告会呈现组内真实成员的昵称、头像、SteamID 与整份游戏库 —— 这是其功能本身，
「别把报告转发到家庭组以外」这条要求即由此而来。

### 与 Steam 服务条款的关系

本节只陈述不确定性所在，不构成任何形式的许可或合规判断。

- **数据源不属于公开文档化的接口。** 读取家庭组所依赖的接口（成员名单、共享库归属、游玩记录）
  在 Valve 的官方 Web API 文档中**没有对应页面**。它们目前可用，但属于未公开接口：可能变更或
  下线，也没有任何官方文件表明此类用法获得许可。
- **脚本化访问为订阅协议第 4.C 条（Automation）的文字范围所覆盖。** 该条禁止使用 scripts /
  bots / macros 或其他 non-human-controlled systems「in any manner」与 Content and Services
  交互；本工具即为脚本化访问，按该条字面表述落在其覆盖之内。其列举的四项示例（自动建号、伪造
  游戏数据、无真实用户投入而获取奖励、以自动化方式参与裁决系统）均不涉及只读访问本人所在家庭组
  的数据，但 including but not limited to 使其外延不限于所列举的情形。
- **两个方向都不存在可援引的先例。** 据现有公开信息，未见针对此类只读、单人、非商业工具的执法
  记录；同样地，也不存在承认该用法合规的官方文件。缺少处罚记录不构成许可。
- **处置权在第 4.D 条（Enforcement），该条规定可以不经通知就限制或终止账号。** 据此，上述不确定性
  的后果由使用者及其 Steam 账号承担；作者一侧的责任排除仅限于 MIT 许可所载范围。

若不接受这一风险，可以不使用本工具：计分规则在「计分规则」一节已完整给出，由组内成员自行申报
所玩的游戏与价格即可手工得出同样结果，无须依赖本工具的数据获取方式。

## 排错

```bash
npm run check
```

它会逐项检查各层并指出中断位置：代理、取价接口、家庭共享判定、家庭组读取、昵称解析。

- **读家庭组返回 401 → 多数情况是 token 被「轮换作废」，而非过期。**
  Steam 页面每加载一次即换发新 token，旧 token 立即失效（即使尚未到期）。
  → 硬刷新家庭组管理页重新获取，**取得后立即执行**，中途不要再打开任何 Steam 页面。
  之后再考虑过期因素（有效期约 24 小时）。
- **价格查得到、家庭组却读不了 → 代理未覆盖 `api.steampowered.com`。**
  读取家庭组只能走 api 域，无降级路径；改用覆盖 api 域的加速器节点，或设置 `HTTPS_PROXY`。
- **提示「这个账号没有加入任何 Steam 家庭组」→ token 有效**，改用组内其他成员的 token 即可。
- **成员显示为「玩家XXXXXX」→ 昵称接口偶发限流**，重新执行一次通常即可恢复；
  价格、归属与计分均不受影响。
- **直接双击 `index.html` 看不到数据 → 属正常现象**：它只是报告模板，本身不含数据。
  执行 `node steam-family.js`（或双击 `run.bat`）才会生成带数据的报告。

## 目录结构

```
steam-family.js        入口：一条命令出报告
run.bat / run.sh       双击入口（Windows / macOS·Linux）
cli.js                 只输出终端报表，不生成 HTML
src/engine.js          计分内核（纯函数、零依赖、无 DOM）
src/steam.js           Steam 接口接入
src/payload.js         字段组装
src/safe-path.js       路径闸门（--from / --out 仅限当前目录）
src/static-report.js   把模板内联成单文件报告
src/app.js             报告的渲染逻辑
index.html styles.css  报告模板
data/sample.json       示例数据
tests/                 测试（含发布闸门）
.github/               CI 与 issue / PR 模板
```
